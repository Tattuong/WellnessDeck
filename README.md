# WellnessDeck

Offline lifestyle dashboard. No diagnosis. Just insight.

Package: `com.WellnessDeckMNG.WellnessDeck`  
Remote IAP: https://api2.blwsmartware.net/N251.json

If `disable` is `1`, Google Play billing popups are hidden. The Shop still sells looks and extras with coins. Bought looks and features apply in-app; you can reset the look to default anytime.

WellnessDeck does not connect to HealthKit, wearables, a microphone, or location.

## Play products

| Product | Type |
| --- | --- |
| `wd_pack_1` … `wd_pack_10` | Consumable coins |
| `wd_remove_ads` | Non-consumable |
